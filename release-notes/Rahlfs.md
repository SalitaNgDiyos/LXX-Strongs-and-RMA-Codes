Tag fixes in LXX Rahlfs+:

- Exod 12:9 ὠμὸν "raw" now has the new number G13149 ὠμός (it was G5606 ὦμος "shoulder")
- Exod 12:9 ἡψημένον "boiled" is now coded as a perfect participle (it was coded aorist)

Unzip and put the `.ot` file in your theWord `Modules` folder. Use it with the Greek Bible Lexicon dictionary (https://github.com/SalitaNgDiyos/Greek-Bible-Lexicon), which has the new G13149 entry.
